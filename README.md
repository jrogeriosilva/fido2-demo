# FIDO2 Demo

Demonstração interativa e visual das cerimônias FIDO2/WebAuthn: **registro** (attestation) e **autenticação** (assertion).

Página estática única, sem dependências de build. Interface bilíngue (português e inglês) com seletor de idioma no topo; a escolha fica salva no navegador.

## Demo

https://jrogeriosilva.github.io/fido2-demo/

## Uso local

Abra `index.html` no navegador, ou sirva o diretório:

```bash
python -m http.server 8000
```
